Project SE400 — Bookstore E-Commerce

Báo Cáo Tích Hợp Paper Vào Project

Phân tích chi tiết những gì project đã áp dụng từ bài báo Bellar et al. 2024 (Mathematics 12, 2403), gồm kiến trúc, luồng hoạt động, mapping khái niệm → file, và các cải tiến vượt phạm vi paper.

1. Bối Cảnh

Paper nguồn

  • Tên: "Sentiment Analysis: Predicting Product Reviews for E-Commerce Recommendations Using Deep Learning and Transformers"
  • Tác giả: Oumaima Bellar, Amine Baina, Mostafa Ballafkih
  • Tạp chí: Mathematics 2024, 12, 2403 (MDPI)
  • Đóng góp chính: benchmark CNN / RNN / Bi-LSTM / BERT / RoBERTa / ALBERT trên dataset Women's Clothing Reviews; chứng minh ensemble (CNN+RNN+Bi-LSTM) thắng mọi mô hình đơn lẻ với accuracy 96.2% (3-class).

Project

  • Domain: bookstore e-commerce (sản xuất, không phải research lab).
  • Stack: Node.js + Express + Sequelize + MySQL backend, React + Vite + TypeScript frontend.
  • Provider AI: Groq Cloud (LLaMA 3.1 8B / 3.3 70B) — chọn LLM thay vì train CNN/RNN/BERT vì lý do production trình bày ở §9.

Mục tiêu áp dụng

  • Lấy tinh thần paper (sentiment-aware recommendation) làm trục chính.
  • Bám đúng phương pháp khoa học (3-class, P/R/F1, ensemble, aspect-level) ở những chỗ không xung đột với production constraints.
  • Khi xung đột (ví dụ train BERT vs gọi LLM API), document rõ trade-off.

4. Pipeline Chi Tiết

4.1. Flow A — Tạo review → Sentiment Analysis

User submits review │ ▼ POST /api/reviews │ ▼ reviewService.addReview() ├─ verify user đã mua (status=DELIVERED) ├─ Review.create() ──────────────────► (1) lưu review NGAY (không chờ AI) ├─ bookInsightService.invalidateBookInsights(bookId) └─ reviewAnalysisService.queueReviewAnalysis(reviewId) ─► async (setTimeout 0) │ ▼ (background, không block response) analyzeAndStoreReview(reviewId) │ ▼ sanitize comment ─► sanitizePii (email, URL, phone, card) │ └─► normalizeText (NFC, dồn whitespace, giảm lặp) ▼ fallbackAnalyzeReview(rating, comment) ──► always run (rule baseline) │ ▼ [if AI_ENABLED && GROQ_KEY] analyzeWithGroq(prompt với aspect schema + Vietnamese) │ (timeout 15s, abort nếu lỗi) │ ▼ ensembleVote(groq, rule, rating) ├─ tally weighted votes ├─ winner_label └─ agreement = winner_weight / total_weight │ ▼ ensembleScore(groq, rule, rating) ─► weighted avg sentiment_score │ ▼ upsertReviewAnalysis (lưu tất cả: aspects, ensemble_*, signals, spam, raw_meta)
Đặc điểm quan trọng:
  • Review lưu thành công kể cả khi AI tắt hoặc Groq lỗi.
  • Rule-based luôn chạy → có nguồn dự phòng và đóng vai trò "Naive Bayes baseline" trong ensemble.
  • Groq optional → khi tắt, ensemble vẫn có rule + rating.
  • prompt_version audit được khi đổi prompt.

4.2. Flow B — Trang chi tiết sách → Insight + Recommendation

User mở /book/:id │ ├──► GET /api/books/:id (chi tiết) │ ├──► GET /api/books/:id/insights │ │ │ ▼ │ bookInsightService.getBookInsights({ bookId }) │ ├─ Review.count() ─► nếu = 0, trả emptyInsight │ ├─ Review.findOne(latest updatedAt) ─► dùng làm cache key │ ├─ BookInsight.findOne({ review_count, updatedAt >= latest }) │ │ └─ HIT ─► trả ngay (không gọi Groq) │ │ MISS ─► │ ├─ findAnalyzedReviews(bookId) │ ├─ buildFallbackInsight (thống kê signals theo sentiment_label) │ ├─ [if AI] Groq tóm tắt thành summary tiếng Việt │ └─ saveInsight (upsert BookInsights) │ └──► GET /api/recommendations/books/:id/similar │ ▼ recommendationService.getSimilarBooks ├─ findBookStats (subquery aggregation, không Cartesian) ├─ findBookInterestIds (genres + authors của sách) ├─ scoreBooks (rating 28%, sentiment 18%, review 13%, sales 13%, wishlist 9%, interest 9%, recency 10%) └─ applyDiversity (MMR-lite: penalty cùng author -0.05, cùng genre -0.03)

5. Pre-processing & Sanitization (Paper §3.2)

"Canonicalization, a process that involves converting text to lowercase, stripping leading and trailing spaces, digits, punctuation, and stop words... Following this, tokenization... and lemmatization..."
Bước paperÁp dụngLý do nếu không
Lowercase❌LLM xử lý case OK, lowercase mất thông tin (tên riêng)
Strip spaces✅ MULTI_WHITESPACE_RE
Strip digits❌Số có nghĩa (rating, giá)
Strip punctuation⚠️ Giảm lặp !!!!!! → !!Punctuation gốc có nghĩa với LLM
Strip stopwords❌Stopwords có ích cho LLM hiểu ngữ cảnh
Tokenization❌LLM tự token hóa
Lemmatization❌Tiếng Việt không inflection nhiều
Unicode NFC✅Tiếng Việt có nhiều cách compose dấu
Strip zero-width✅Bảo mật, tránh hidden tokens
Giảm ký tự lặp aaaaaaaa → aaa✅Teencode/spam

Bổ sung — PII sanitize:

EMAIL_RE → '[email]'
URL_RE   → '[url]'
PHONE_RE → '[phone]'    // VN format: +84, 0xx
CREDIT_CARD_RE → '[card]'

6. Polarity & 3-Class Setup (Paper §3.3, §4.1)

Paper Section 4.1 chứng minh 3-class > 5-class (RNN-Word2Vec F1 89.78% vs 84.47%).

  • sentiment_score DECIMAL(5, 4) clamp ∈ [-1, 1]
  • sentiment_label chỉ lưu 3 giá trị
ensembleScore = (groq*0.5 + rule*0.2 + rating_label*0.3) / totalWeight

7. Aspect-Level Sentiment (Paper §2.1)

"Sentiment analysis extraction operates at three levels: sentence level, document level, and aspect or feature level."

Schema cố định 5 aspects

Aspect keyÝ nghĩa
content_qualityNội dung sách
translationChất lượng dịch
print_qualityChất lượng in / giấy / bìa
shippingGiao hàng / đóng gói
price_valueGiá trị so với giá tiền

Mỗi aspect: positive | neutral | negative | none. none quan trọng — không bịa giá trị.

Use case mở khóa: "Book B rating 4.7 nhưng chất lượng in xấu" → WHERE avg_rating >= 4.5 AND aspects.print_quality = 'negative'

8. Ensemble Vote (Paper §4.4) ⭐

ModelF-ScoreAccuracy
RNN-Word2Vec89.78%94.85%
CNN+RNN+Bi-LSTM91.3%96.2%
SourceTrọng sốMô tả
groq0.5LLM context-aware, hiểu sarcasm/teencode
rule0.2Rule-based VN keyword + rating-derived
rating0.3Rating người dùng (1-5 → label)
 
counts = { positive: 0, neutral: 0, negative: 0 }
for each vote: counts[vote.label] += vote.weight
winner = argmax(counts)
agreement = counts[winner] / sum(counts)
{
  "sentiment_label": "positive",
  "sentiment_score": 0.78,
  "ensemble_agreement": 0.85,
  "ensemble_sources": {
    "groq": "positive",
    "rule": "positive",
    "rating": "positive"
  }
}
Tại sao ensemble giúp:
  • Khi Groq lỗi → vẫn ra label nhờ rule + rating.
  • Khi Groq sai do sarcasm → rating "kéo về" sự thật.
  • agreement < 0.6 = tín hiệu admin re-check.

Diversity (MMR-lite)

for each picked book:
  if next_candidate cùng author → -0.05 score
  if next_candidate cùng genre → -0.03 score

13. Tiếng Việt Support (Paper §5 Limitation 2)

1. Prompt explicit

You are analyzing a Vietnamese bookstore product review.
Language: Vietnamese (may include teencode, slang, regional words, mixed English).
Interpret accordingly. Negation words (khong, chua, chang, "khong tot", "chua hay") flip sentiment.

2. Rule-based VN keyword

Danh sách từ tích cực/tiêu cực không dấu, đối phó được khi user gõ không dấu.

3. NFC normalization

Dấu tiếng Việt có nhiều cách compose, normalize NFC để match keyword nhất quán.
